# Jan Aadhaar Smart Chatbot

A Flask-based AI chatbot that provides Jan Aadhaar information using predefined FAQs and Google's Gemini AI.

## Features

- User Login
- AI Chat using Gemini
- FAQ-based Responses
- Chat History
- Search Chat History
- Delete Individual Chat
- Clear Chat History
- Download Chat History as PDF
- Dashboard with Analytics
- Dark Mode
- Voice Input (Microphone)

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Google Gemini API
- ReportLab
- OpenPyXL

## Installation

```bash
pip install -r requirements.txt
python app.py
```
